# TokenPylon recorder releases

Signed binaries of the TokenPylon recorder. Source is not published here.

Install (macOS, Linux): `curl -fsSL https://tokenpylon.com/install.sh | sh`
Windows (PowerShell): `& ([scriptblock]::Create((irm https://tokenpylon.com/install.ps1)))`

Details and privacy: https://tokenpylon.com/recorder · https://tokenpylon.com/privacy

A personal tool, shared as it is. No support is promised.
